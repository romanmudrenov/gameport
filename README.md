# Cyber Contra 3D

Браузерный 2.5D/3D экшен-платформер в духе классической **Contra**, построенный на модульной архитектуре ES6 без внешних ассетов и сборщиков.

## Системная архитектура
* **Рендер**: Three.js (WebGL) с процедурными Canvas-текстурами.
* **Аудиоподсистема**: Собственный программный 8-bit синтезатор на базе `Web Audio API` (`js/audio.js`).
* **Модульность**: Чистые ES-модули (`import` / `export`), готовые к прямому запуску через GitHub Pages.

## Управление
* `A` / `D` — Движение
* `W` / `S` — Прицеливание в 8 направлениях и приседание
* `Space` — Прыжок (`S + Space` — спрыгнуть с платформы вниз)
* `J` / `Z` / `ЛКМ` — Стрельба
* `M` — Вкл/Выкл музыку синтезатора
